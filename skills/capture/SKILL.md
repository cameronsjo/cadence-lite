# Capture

Catch the idea without leaving the work. The failure this prevents: a good idea dies in conversation scrollback, or derails the task it interrupted.

## Steps

1. **Record it verbatim.** One or two lines in the user's own words, before any judgment about merit.
2. **Triage it fast.** One decision: act now only when it blocks the current task; everything else gets filed.
3. **File it durably.** An issue on the owning repo, a line in the active plan, or a dated note in the repo's docs — a named place that survives the session, never just the conversation.
4. **Return to flow.** Confirm the capture in one line and resume the interrupted work.
