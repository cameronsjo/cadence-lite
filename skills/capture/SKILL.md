# Capture

Catch the idea without leaving the work. The failure this prevents: a good idea dies in conversation scrollback, or derails the task it interrupted.

## Steps

1. **Record it verbatim.** One or two lines in the user's own words, before any judgment about merit.
2. **Triage it fast.** One decision: act now only when it blocks the current task; everything else gets filed.
3. **File it durably.** Use the project's capture location or a dated local note — a clearly non-authoritative place, never a line in the active execution plan, so a later session can't read a captured idea as approved work. File an external issue only when the user's request or standing workflow authorizes that destination. Promote a captured idea into the active plan only with explicit authorization; capturing it does not authorize implementing it.
4. **Return to flow.** Confirm the capture in one line and resume the interrupted work.
